# v0.7.6 — tougher enemies for more players

- **Difficulty for more players:** with friends in the game, every enemy gets more health - +50% for each
  extra player (2 players: x1.5, 3 players: x2). Works in the campaign and in Horde. The host can change it
  in `ue4ss/Mods/T2Coop/config.txt`: `enemy_hp=50` (percent per extra player), `enemy_hp=0` turns it off.

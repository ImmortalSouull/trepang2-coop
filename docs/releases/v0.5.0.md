# v0.5.0

- **Co-op menu (F4)** in the main menu and in game: Host, Next arena, type the join address + Join, Leave,
  list of players, network mode switch. The F5–F8 keys still work.
- **Player names**: Steam names (or `name=` in config.txt) over the partner markers, in the menu and instead of
  the "NONE" label when you aim at a partner; "X joined" / "X left" notices.
- **Steam mode (experimental)**: no port forwarding - switch it in the F4 menu (both players, restart the game),
  the friend joins with the host's SteamID64 shown in the menu. Not yet tested between two different Steam
  accounts; if it does not connect, switch back to IP mode.
- The host notices a partner who left within 5 seconds (was about a minute).

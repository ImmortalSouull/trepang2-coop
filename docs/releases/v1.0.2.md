# v1.0.2 — Steam joins fixed

From a player's UE4SS.log: joining a friend by SteamID never got through - "reconnecting 1/16, 2/16, ..." forever.

- **A Steam connection is no longer cut short.** Connecting through Steam takes longer than by IP, and the mod's
  reconnect check started a new attempt 4 seconds after the first one began - killing it, and every attempt
  after it. The mod now waits while a connection is still being made (up to 45 s for Steam, 25 s for IP).
- **Joining by SteamID while the game is in IP mode** is now refused with a clear message
  ("F4 - IP / STEAM MODE, then restart the game") instead of failing again and again. The log line now also
  says which network mode the game is in.

Checked: 4 players joining + 2 level restarts (everyone back each time), the join-in-progress detection
while connecting, the SteamID join in IP mode (message shown, no retry loop).

# v0.9.1 — progress for partners

- **Progress for partners:** missions finished and HVTs killed together used to be saved only in the host's
  game. Now every partner gets them in their own unlocks too (sent when joining and whenever something new is
  finished), so the campaign moves on for everybody.
- **Rejoining:** if a partner's game crashes, they restart it and join again - they're put back next to the
  host in the running mission (checked).

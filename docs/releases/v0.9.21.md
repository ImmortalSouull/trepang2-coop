# v0.9.21 — Steam fix, VPN sync, EXTRAS, F6 quick access

- **Steam mode fixed:** switching to Steam asked to restart the game again after every restart (the game wrote
  its old network setting back when it closed). The mode is now set after the game closes - one restart is enough.
- **Smoother over a VPN / the internet:** the game limited every player to ~10 KB/s and 30 updates a second, which
  made everything lag and drift apart over Radmin/Hamachi/ZeroTier. The host now allows 200 KB/s and 60 updates
  (`net_rate` in config.txt; lower it on a slow connection).
- **Partners get back in after an arena change:** sometimes a partner was stuck in the main menu after the host
  switched arenas. Fixed: 7 arena changes in a row, the partner came back every time. All 47 Horde arenas checked.
- **F4 menu in three short tabs:** CO-OP, LOOK, EXTRAS - half the height it was.
- **EXTRAS** (optional, each player sets their own in F4 - EXTRAS; all off = the game as it is):
  health regen up to 50 / 75 / 100 %, max armor 100 / 200 / 300, auto resupply (a magazine for every gun,
  a grenade and some focus every 60 or 30 s), resupply on every kill, heal on execution (+25 / 50 % / full),
  keep your weapon mods on guns you pick up (pick them once in the weapon menu), remember cheats between game
  launches, randomizer (random weapon mods and colours, enemies' guns random colours).
- **F6 quick access:** weapon mods anywhere; in the safehouse missions, outfit, combat simulator and cheats;
  in Horde the shop (partners too).
- Fix: a partner could be moved to the host by mistake right after a level change.

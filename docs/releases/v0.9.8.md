# v0.9.8 — slow-mo for partners

- **Slow-mo for partners:** a partner's slow-mo (Q) never worked in co-op - the game switches it on through
  the server, which doesn't know the partner's own body. Now the mod catches the partner's Q and the host slows
  time for everybody for 5 seconds (Q again ends it early; 10 s cooldown). The host's own slow-mo already slowed
  time for everyone.

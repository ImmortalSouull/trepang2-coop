# v0.9.4 — performance

- **Performance:** the mod's own work per frame is about half of what it was (measured in a Horde fight:
  host 1.7 s -> 1.1 s and partner 1.9 s -> 0.8 s of script time per 20 s of play). The game engine object and the
  local controller are no longer looked up again and again, and frequent checks run less often where it can't be
  noticed. Everything was checked again afterwards (reload/shots for the partner, spectating, menus, interactions,
  objective markers).

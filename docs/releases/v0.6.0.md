# v0.6.0 — campaign co-op (first steps)

- **Story missions in co-op (early).** Start the campaign as usual; in the safehouse or in a mission press
  **F4 → HOST**: the level reloads from your last checkpoint with the server on, and your friend joins.
- **The host leads the group.** Picking a mission at the safehouse map table, the helicopter ride, the next
  level, "load last checkpoint", "restart level" — wherever the host's game goes, friends follow
  automatically (they reconnect on their own, ~30–40 s while the level loads).
- **Story triggers are shared.** Objective texts, doors and other scripted events the host sets off also run
  for friends; a friend walking into a trigger sets it off for everyone. Enemy squads are spawned only by the
  host and seen by everyone. Friends' games no longer autosave over their own campaign.
- **Down & revive works in missions;** if everyone is down, the group goes back to the last checkpoint.
- Partner's gunshots now have sound and muzzle flash for the host.
- Fixes: crashes during level changes (a stock UE4SS mod, CheatManagerEnabler, is now switched off; the
  mod no longer runs Lua for every spawned object); a broken network setting in Engine.ini could stop
  hosting silently — the mod and the installer now repair it.
- Still rough: cutscenes and some scripted scenes are not synced yet (planned for v0.7). Only the start of
  Cultists was tested in co-op so far.

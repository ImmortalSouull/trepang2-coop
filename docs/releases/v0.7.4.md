# v0.7.4 — shared interactions, objective markers, human shields, partner fire

- **Interactions are shared.** Everything used with the interact key (terminals, buttons, levers,
  elevators, scripted "player interaction" scenes like forcing the cultists' heavy doors): when a partner
  uses one, the host's game does it too (with the partner's body), so the story moves on for everyone;
  when the host uses one, partners see it happen. Interactables the host's story switches on or off are
  switched the same way for everyone (a partner can now use a terminal the story just enabled).
  Personal things (intel, collectables, pickups, crates) stay per player.
- **Objective markers** the story shows, hides or moves ("find the Enforcer", distance through walls)
  appear for every player, also for a friend who joins later.
- **Human shields:** a partner can grab an enemy, hold it, let it go or throw it - the real enemy on the
  host follows, and everyone sees who holds whom.
- **Partner fire:** incendiary rounds, molotovs and other fire from a partner set the real enemies on fire
  (burn damage counts); enemies burning on the host burn on every screen.
- **Fix:** the Horde HUD on the partner's screen showed "enemies left: 0" - it shows the host's count again.

# v0.5.1

- **Steam invites** (Steam mode): the host presses **INVITE (STEAM)** in the F4 menu and picks a friend in the
  Steam overlay. The friend accepts the invite and joins automatically - if their game was closed, Steam starts
  it and it connects once the main menu is up.
- **"Join game" in the Steam friends list** works for a friend who is hosting co-op.
- The F4 menu lists **Steam friends who are hosting** right now - click a name to join.
- Done by a small native helper (`t2coop_steam.dll`) that talks to the game's own Steam API.
- Still experimental: accepting an invite could not be tested on a single Steam account. Players on a
  non-Steam copy of the game can only use IP mode.

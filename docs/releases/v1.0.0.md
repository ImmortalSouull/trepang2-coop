# v1.0.0 — The whole campaign in co-op

**Trepang2 Co-op 1.0** - play the whole Trepang2 campaign and Horde together (up to 3 players).

What 1.0 means: every campaign map, every Horde arena and every side mission has been played in co-op by two
game copies, with joins, level restarts, checkpoint reloads, mission ends and the credits. No known bug blocks a
play-through. Boss fights are shared like every other enemy (health bars, damage from every player), but their
special scripted scenes have not been played start to finish in co-op yet - please report how they go.

Since the last version:
- Final regression run: all 50 Horde arenas (partner joins / follows every arena change), all campaign maps
  (join + 3 level restarts each), mission ends (Ghosts, Syndicate -> safehouse together), the credits, long
  fights on Horde and KillMothman - no crashes.
- Showcase video of the campaign co-op.

The road to 1.0 (0.9.22-0.9.30): enemy looks that froze the game left out, LOOK preview crash, partner crash on
checkpoint reload, the end of the game, rescue when falling off the map, elevators / roll-up doors / laser gates
for everyone, partners told when the host leaves, host crash on level changes (stale messages), partner crash
after a mission end (a slow join that went through after being given up).

Next: co-op for up to 4 players.

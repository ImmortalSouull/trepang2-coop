# v0.6.4

- **English install guide** (README.txt) in the zip. Short version: unpack anywhere, run install.bat, start the
  game, press F4.
- **Custom Horde maps**: load any Horde map (also community maps that the arena list doesn't know), press
  F4 -> HOST - that map is hosted. Horde maps are now recognised by the Horde mode in the level, not by name.

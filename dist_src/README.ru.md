# Trepang2 Co-op (альфа)

Мод добавляет в Trepang2 кооператив на двоих (и больше) в режиме «Орда» (Survival).
Работает на встроенной сети Unreal Engine + мод-загрузчик UE4SS.

## Установка (обоим игрокам)
1. Закройте игру.
2. Распакуйте архив и запустите `install.bat`. Он сам найдёт игру в Steam.
3. Запустите игру один раз. Если мод напишет «restart the game once» — перезапустите.

## Как играть
| Клавиша | Что делает |
|---|---|
| **F8** | выбрать арену «Орды» (по кругу, ~40 арен) |
| **F5** | создать кооп на выбранной арене (вы — хост) |
| **F6** | подключиться к хосту (IP из `config.txt`) |
| **F7** | выйти из коопа в главное меню |

Можно нажимать прямо в главном меню.

### Подключение через интернет
Хосту нужен открытый **UDP-порт 7777**. Варианты:
- открыть порт 7777 (UDP) на роутере и дать другу свой внешний IP;
- или оба запускают **Porthole** / **Radmin VPN** / ZeroTier и используют выданный там IP.

IP хоста пишется в файл
`Trepang2\CPPFPS\Binaries\Win64\ue4ss\Mods\T2Coop\config.txt` → `join_ip=...`

## Что работает
- общая арена, волны врагов от хоста, игроки видят друг друга;
- стрельба и урон по врагам у обоих, смерти врагов синхронизированы;
- HUD волны / врагов / денег у подключившегося;
- **ранение вместо смерти**: при ≤30% здоровья вы «падаете», напарник рядом за 3 с поднимает;
  если упали все — арена перезапускается, подключившиеся возвращаются сами.

## Известные ограничения альфы
- хост видит напарника всегда с пистолетом (смена оружия не передаётся);
- магазин/деньги «Орды» работают у хоста;
- над напарником у хоста может появляться подпись «NONE»;
- сюжетные миссии пока не поддерживаются;
- пока мод установлен, в настройках игры стоит сетевая подсистема `Null`
  (нужна для сервера). Чтобы вернуть как было — удалите секцию `[OnlineSubsystem]`
  из `%LOCALAPPDATA%\CPPFPS\Saved\Config\WindowsNoEditor\Engine.ini`.

## Удаление
Удалите из `Trepang2\CPPFPS\Binaries\Win64` файл `dwmapi.dll` и папку `ue4ss`.

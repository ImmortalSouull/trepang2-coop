# v0.9.10 — loading-screen freeze fixed

- **Fix: the rare freeze when starting to host or changing levels.** The game sometimes froze (no crash, no
  response) right after the host started a level or after a level change. Found with a stack snapshot of the
  frozen game: the mod closed the "press any key" loading screen in a way that could collide with the loading
  screen still drawing on its own thread, and both waited for each other forever. Now it presses "any key" the
  way the game itself does. Checked: 12 host starts with a partner joining and 4 level restarts in a row - no
  freezes (before, about 1 in 10-25).

# v0.4.3

- **The partner's kicks and sword swings now damage enemies on the host** (kick damage and headshot
  multiplier from the game, sword damage from the weapon), and these kills earn Horde money.
- Verified with test kicks; please report if a real kick or sword swing doesn't count.
- The kick is read from the default Melee key (right mouse button).

Known issues: a "NONE" label when the host aims at a partner; internet play needs UDP port 7777
(or Porthole / Radmin VPN / ZeroTier); story missions aren't supported yet.
